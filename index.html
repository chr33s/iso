Limit the network.

Set egress to none to cut routes beyond your Mac, or filtered to allow only listed hosts. Guests can still reach services on the Mac itself.

Secrets and an audit trail.

iso secrets encrypts local secrets with a passphrase and this Mac’s Secure Enclave key. iso audit records boundary events and variable names, never values.

Less access. On purpose.

The provider-only preset disables direct guest internet access, requires the credential proxy, and stages file returns. Set a session deadline, too.

proxy requiredstaged pulls8h session TTL

Hardening is opt-in; the default is networked. No-egress mode can still reach services on your Mac. A VM is a boundary, not a guarantee. Read the trust model ↗

# Build the host, proxy, and VM runtime.
git clone https://github.com/chr33s/iso.git
cd iso
python3 scripts/build-release.py --release

Extract the archive in .build/release-archive/ and install all four executables (iso, iso-proxy, iso-egress, iso-sandbox) together on PATH. The Apple container service and guest kernel are also required. Backend setup ↗ 

iso setup
cd ~/code/my-project
iso up
iso claude # or: iso codex
iso code . # or: iso zed .

Run after installing the binaries. iso code and iso zed open the project's VM in your editor over SSH. Configure provider authentication before launching your agent. Configuration guide ↗

Fork: a Swift fork of Trail of Bits’ coop. Configuration lives in ~/.iso/config.jsonc.
